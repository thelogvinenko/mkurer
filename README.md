# Курьер — сайт на Hugo

Готовый статический проект без внешней темы, Node.js, базы данных и платного хостинга. Подготовлен для GitHub Pages. Репозиторий: https://github.com/thelogvinenko/ikurer . Целевой адрес GitHub Pages: https://thelogvinenko.github.io/ikurer/ . Публикацию выполняет GitHub Actions.

## Страницы

- `/` — главная страница курьеров Магнит Доставки: калькулятор, преимущества, этапы регистрации и FAQ.
- `/magnit/` — перенаправление на главную, чтобы прежняя ссылка продолжала работать.
- `/yandex/` — ранее подготовленная страница, не представлена в навигации главной.
- `/404.html` — страница ошибки.

Все кнопки регистрации Магнита ведут на `https://magnit-kurier.ru/?ref=MG670049EC`.

## Понятная структура

```text
hugo.toml                    Название сайта, описание и ссылки регистрации
content/
  _index.md                  Метаданные и изображения главной Магнита
  yandex.md                  Метаданные и изображение Яндекс Еды
layouts/
  index.html                 Главная Магнит Доставки
  404.html                   Страница ошибки
  _default/
    baseof.html              Общий HTML, SEO и подвал
    yandex.html               Страница Яндекс Еды
  partials/
    magnit-page.html         Содержимое главной Магнита
    header.html              Общая шапка
    registration.html        Единая кнопка регистрации Магнита
static/
  image/                     ВСЕ картинки; публикуются по адресу /image/...
    magnit-card.png           Фото Магнита на главной
    magnit-hero.png           Фото в первом экране Магнита
    magnit-logo.png           Логотип
    yandex-courier.svg        Временная иллюстрация Яндекс Еды
    reference-*              Скачанные изображения из предоставленного HTML
    sources.json             Адреса оригиналов и сведения о загрузках
  css/style.css              Вся адаптивная вёрстка
  js/calculator.js           Пересчёт дохода в браузере

```

## Как поменять картинки и тексты

1. Замените файл в `static/image/`, сохранив имя, — шаблон сразу подхватит новую картинку.
2. Для другого имени или расширения поменяйте путь в `content/_index.md` либо `data/magnit.json`. Путь записывается без `static/`, например `image/my-photo.jpg`.
3. Главное фото и логотип задаются в `content/_index.md`: `heroImage` и `logoImage`.
4. Текстовые блоки редактируются в `data/magnit.json`, компоновка — в `layouts/partials/magnit-page.html`.
5. После загрузки изменений в `main` GitHub Actions пересоберёт сайт.

Иллюстрация `yandex-courier.svg` — временная локальная иллюстрация, её можно заменить на свою фотографию. Из исходного HTML скачаны 43 уникальных изображения: для одного недоступного оригинала сохранена WebP-версия из того же HTML. Исходники и адреса перечислены в `sources.json`. В рабочей вёрстке используются только локальные файлы. Счётчики, чужие формы, ключи API и геолокация из исходника не перенесены.

## Ссылки регистрации

В `hugo.toml`:

```toml
[params]
  magnitRegistrationURL = 'https://magnit-kurier.ru/?ref=MG670049EC'
  yandexRegistrationURL = ''
```

Укажите вашу ссылку в `yandexRegistrationURL`, когда она будет готова. На странице `/yandex/` появится кнопка перехода на эту ссылку; главная посвящена Магнит Доставке.

## Локальный запуск

Нужен Hugo **0.145.0 или новее**, обычной версии достаточно. Установщик и инструкции: https://gohugo.io/installation/ . Node.js и npm не нужны.

Из корня проекта:

```bash
hugo server --bind 127.0.0.1 --port 1313
```

Откройте http://localhost:1313/ . Hugo автоматически обновляет страницу при изменении файлов. Для остановки нажмите Ctrl+C.

Сборка и проверка:

```bash
hugo --gc --minify
python3 scripts/check_site.py
```

Если окружение запрещает запись в стандартный кэш, передайте `--cacheDir /tmp/ikurer-hugo-cache`.

Для проверки размещения в подкаталоге репозитория:

```bash
hugo --gc --minify --baseURL https://example.github.io/ikurer/ --destination /tmp/ikurer-subpath
python3 scripts/check_site.py /tmp/ikurer-subpath /ikurer
```

## Публикация на GitHub Pages после входа в аккаунт

1. Создайте пустой репозиторий GitHub. Для обычного бесплатного аккаунта используйте публичный репозиторий.
2. Загрузите в него исходники проекта, включая `.github/workflows/hugo.yml`. Ветка — `main`. Папку `public/` загружать не нужно.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Откройте **Actions → Deploy Hugo to GitHub Pages → Run workflow**, если автоматический запуск ещё не состоялся.
5. Дождитесь успешных задач `build` и `deploy`. GitHub покажет адрес сайта в Settings → Pages и в окружении `github-pages`.

Workflow сам получает правильный базовый адрес от GitHub Pages, поэтому изображения и внутренние ссылки работают и на `USERNAME.github.io`, и на `USERNAME.github.io/REPOSITORY/`. В конфигурации задан адрес `https://thelogvinenko.github.io/ikurer/`; при публикации Actions получает актуальный адрес из настроек GitHub Pages. Для другого способа публикации задайте реальный `baseURL` вручную.

Если будете загружать через Git из этой папки:

```bash
git init -b main
git add .
git commit -m "Create Hugo courier website"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Замените USERNAME и REPOSITORY на свои значения. В управляемом окружении Codex каталог `.git` может быть защищён; в этом случае используйте обычную копию проекта из ZIP-архива и выполните команды в ней.

## Калькулятор

Сохранены **1611** записей из переменной `devCalcData` предоставленного HTML. Формула исходной страницы:

```text
За месяц = округлить(тариф / 30 / 12 × часы в день × дни в месяц)
За неделю = округлить(доход за месяц / 4)
Доход в первом экране = округлить(тариф / 30)
```

Диапазоны: 4–12 часов, 1–30 дней. По умолчанию Москва, машина, 6 часов, 22 дня: **106 920 ₽/месяц**, **26 730 ₽/неделю**. Москва, пешком, 5 часов и 22 дня: **23 100 ₽/месяц**, **5 775 ₽/неделю** — совпадает с сохранённым состоянием калькулятора в образце.

Расчёт автономный: сторонний API не нужен. Тарифы — снимок предоставленных данных, они не обновляются автоматически и не являются гарантией дохода. Для обновления замените значения `avto`, `velo`, `evelo`, `foot` в `data/rates.json`, сохранив идентификаторы и структуру записей.
